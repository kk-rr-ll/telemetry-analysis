# Анализ телеметрии космического аппарата (Детекция аномалий)

Данный проект посвящен обработке и анализу телеметрических данных космического аппарата (КА), а также сравнению различных подходов к обнаружению нештатных ситуаций (аномалий).

## 📌 Описание данных

В датасете `telemetry_dzz_sem1.csv` содержатся временные ряды основных параметров аппарата:
* `timestamp` — временная метка;
* `mode` — режим работы КА (`standby`, `imaging`, `attitude_control`, `downlink`);
* `temperature` — температура (°C);
* `voltage` — напряжение (В);
* `current` — сила тока (А);
* `angular_velocity` — угловая скорость (рад/с).

---

## 🚀 Реализованные подходы к детекции

В ходе работы были разработаны и сопоставлены три алгоритма детекции аномалий:

1. **Детектор №1 (Жёсткие пороги):**
   * **Принципы:** Пороговая проверка фиксированных критических значений ($T > 50^\circ\text{C}$, $U < 24\text{В}$, $I > 8\text{А}$, $\omega > 1.0$).
   * **Результат:** 47 аномальных точек.
   * **Недостаток:** Не учитывает контекст (режимы работы) — штатная максимальная нагрузка во время передачи данных воспринимается как авария.

2. **Детектор №2 (Статистический — правило $2\sigma$):**
   * **Принципы:** Поиск отклонений, превышающих 2 стандартных отклонения ($> 2\sigma$) от глобального среднего.
   * **Результат:** 64 аномальные точки.
   * **Недостаток:** Объединение всех режимов работы в общую выборку дает ложные срабатывания на мультимодальных распределениях.

3. **Детектор №3 (Комбинированный score + динамика):**
   * **Принципы:** Суммирование баллов подозрительности по нескольким параметрам одновременно + учет скорости изменения значений (`diff`). Состояние считается аномальным при $\text{Score} \ge 2$.
   * **Результат:** 22 аномальные точки.
   * **Преимущество:** Значительно снижает количество ложноположительных срабатываний за счет учета комплексных сбоев и резких скачков.

## 📊 Сравнение детекторов

| Детектор | Точки | Используемые признаки | Главный недостаток |
| :--- | :---: | :--- | :--- |
| **№1 — Пороги** | 47 | Фиксированные физические пороги | Игнорирует режим работы КА |
| **№2 — Статистика** | 64 | Отклонение $> 2\sigma$ от среднего | Чувствителен к мультимодальным данным |
| **№3 — Комбинация** | 22 | Баллы по порогам + динамика (`diff`) | Требует тонкой ручной настройки подбора весов |
